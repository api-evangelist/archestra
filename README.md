Archestra AI provides open-source infrastructure for enterprise AI, enabling platform teams to deploy AI models securely and at scale. Their platform offers a controlled gateway for AI agents and clients, handling data access, tool integration, and policy enforcement. Features include an MCP gateway, LLM proxy, identity management, and observability tools, all designed to keep data governance while accelerating AI production across organizations.

**Areas:** AI Infrastructure · MCP Gateway · LLM Proxy · Observability · Open Source

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Archestra AI: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
